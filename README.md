# Канцелярский переполох — Лунный свет

Мобильная веб-игра: нажимайте на падающую канцелярию, избегайте клякс. Текущая версия — прототип с тестовыми сертификатами, без серверной выдачи призов.

## Запуск
Нужен Python 3. Из корня репозитория:
```sh
python3 -m http.server 8080 --directory dist
```
Откройте http://localhost:8080. Сборка и установка зависимостей не требуются.

## Файлы
- dist/index.html — интерфейс
- dist/style.css — адаптивное оформление
- dist/game.js — механика, очки, таймер
- dist/assets/logo.png — логотип из предоставленного исходника
- PROJECT_HANDOFF.md — правила, архитектура и следующие задачи

## Размещение
Каталог dist можно разместить на статическом HTTPS-хостинге.
Тестовая версия: https://lunsvet-pencil-rush.bouncysquid9.chatgpt.site
Она размещена в Sites с закрытым доступом. GitHub не синхронизируется с Sites автоматически; push в этот репозиторий сам по себе не обновляет игру.

## Статус
Перенесена версия с автоматическим ускорением каждые 5 секунд. Реальные сертификаты, авторизация, серверная проверка результата и админка ещё не реализованы.
